# Branding

The game ships with Pip, an original paper-robot badge (`src/paper/sprites.tsx`).

The NASA insignia ("meatball"), logotype ("worm") and seal are protected marks
(14 CFR Part 1221). NASA's media usage guidelines do not allow them on
non-NASA products without written permission, and NASA Space Apps asks
participants not to use them. Text references to NASA and its data are fine.

If you have written permission to use a specific mark, put it here as
`logo.svg` or `logo.png`. It replaces the Pip badge in the header automatically.
